# Sales Analysis Project

## 📌 Project Objective
Analyze sales data to identify sales trends, profitable products,
and top-performing regions.

## 🛠️ Tools Used
- Microsoft Excel
- PostgreSQL
- Power BI
- Python

## 📊 Key Analysis
- Total Sales
- Total Profit
- Top Products
- Regional Sales
- Monthly Sales Trends

## 💡 Business Insights
- Identify the best-performing products.
- Compare sales across different regions.
- Analyze monthly sales trends.
- Find products with high sales and low profit.
